Your own machinefree · zero cloud

Any Mac/Linux box with Docker and ~2 TB free disk. The node runs right here — no account, no bill, no keys to anyone:

git clone https://github.com/ivcained/fiddy && cd fiddy
export PATH="$PWD/bin:$PATH"
bin/fiddy node up --local

Bootstrap still downloads ~470 GB (overnight on home broadband). A sleeping laptop pauses the node — it catches up when it wakes. Perfect for trying everything; move to a server later if you want it always-on.

AWS~$285/mo · default cloud path

Open AWS CloudShell ↗

CloudShell opens pre-authenticated in your account. One line inside:

curl -fsSL https://raw.githubusercontent.com/ivcained/fiddy/main/scripts/aws-deploy.sh | bash

New AWS account? CloudShell stays locked during account verification (can take up to 2 days) — no retry helps. Same command works from your own terminal meanwhile: install the AWS CLI, run aws configure once, then paste the same line.

Why AWS is the default: Hetzner caps new accounts at 1024 GB of volume storage — a resize past that is refused with resource_limit_exceeded, which is not enough for an unmodified node restore. A brand-new Hetzner account cannot follow this tutorial to the end. AWS lets the root volume simply be 2 TB, so the default is AWS.

Hetzner~€120/mo · cheapest cloud

Get an API token at console.hetzner.cloud (project → Security → API tokens), then:

export HCLOUD_TOKEN=…
git clone https://github.com/ivcained/fiddy && cd fiddy && bash scripts/hetzner-deploy.sh

Roughly a third of AWS's price and fully supported once your account's volume quota has been raised past 1024 GB — new accounts are capped below what the node needs (see the AWS note above).

OVHcloud~$190/mo

Create API credentials at api.ovh.com/createToken (GET+POST on /cloud/*), then:

Budget VPS — manual orderfrom ~€24/mo · no API, so no one-click

Cheapest machines anywhere, but you order through their website (10 minutes of form-filling), then one command does the rest: bin/fiddy provision --ssh root@<your-ip>. Mind the disk: a mainnet node needs ~2 TB — most budget plans ship far under it.

• MivoCloud S8 — €40/mo (Moldova): add "Disk 2 · 1TB HDD" (+€5) to reach 2 TB.
• Advin Servers — $24/mo: 8 vCPU/16 GB but 256 GB disk — too small unless you upgrade storage.
• Contabo VPS 8 — €14/mo: 8 vCPU/24 GB, 300 GB — needs their storage add-on to fit 2 TB.
• LuxVPS EPYC: 6 vCPU/32 GB, 340 GB — too small as listed.
HDD is fine — bootstrap is just slower. fiddy provision --ssh measures the disk and refuses loudly if a box can't hold the node.

Already have a server? Skip ahead — any Ubuntu box with 4 vCPU / 16 GB / 2 TB works. Hetzner & OVH paths are scripted against their API docs, not yet battle-tested; they fail loudly if anything drifts.
